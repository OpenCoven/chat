# iOS Phase D1: chat-ios Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `OpenCoven/chat-ios` — a SwiftUI app linking `cave-core` and `coven-transport` through a UniFFI bridge, with an XCFramework pipeline, CI that fails on any GPL dependency, and a Keychain adapter that stores credentials with the right accessibility class.

**Architecture:** The app is a thin Swift shell over Rust, following the structure Coven Pocket already proves out: a `rust/ffi` crate holding every UniFFI derive, a `rust/bindgen` binary generating Swift, and a script assembling an XCFramework consumed by an XcodeGen-generated project. The shared SDK crates stay FFI-free; `chat-ios-ffi` is the only place UniFFI appears, and it converts at the boundary. Two additive SDK changes land here because this is the first consumer that needs them.

**Tech Stack:** Swift 6, SwiftUI, iOS 17 minimum, XcodeGen, SwiftLint, UniFFI 0.32, Rust 1.95.0, tokio, rustls.

**Depends on:**
- `2026-08-16-ios-phase-a-transport-extraction.md` — `coven-transport` exists.
- `2026-08-16-ios-phase-b-cave-core-foundation.md` — `cave-core` exists with the v1 contract types.
- `2026-08-16-ios-phase-c-enrollment-authority.md` — Cave's `enrollment-payload.ts` defines the payload format this phase decodes. Phase C need not be *deployed*, but its payload format must be settled, since the round-trip vectors are copied from its tests.

**Boundary:** No QR scanning, no enrollment flow, no network calls to a real Cave, no conversation UI, no caching. Those are D2. This phase ends with an app that builds, links Rust, and stores a secret.

```rust
/// A POST to perform against an endpoint.
#[derive(Debug, Clone)]
pub struct PostRequest {
    /// Request path, including any query string.
    pub path: String,
    /// Body, sent as `application/json`.
    pub body: String,
    /// Extra headers as name/value pairs.
    pub headers: Vec<(String, String)>,
}

/// Reject any value that could terminate a header line early.
///
/// Without this, a caller-supplied header value or path could inject
/// additional request lines into the wire format.
fn is_header_safe(value: &str) -> bool {
    !value.contains('\r') && !value.contains('\n')
}

/// Perform one POST against an endpoint, under a single timeout budget.
pub async fn post_endpoint(
    endpoint: &Endpoint,
    request: &PostRequest,
    timeout: Duration,
) -> Exchange {
    if !is_header_safe(&request.path) {
        return Exchange::Failed("request path contains a line break".to_string());
    }
    for (name, value) in &request.headers {
        if !is_header_safe(name) || !is_header_safe(value) {
            return Exchange::Failed(format!("header {name} contains a line break"));
        }
    }

    let mut head = format!(
        "POST {} HTTP/1.1\r\nHost: coven\r\nConnection: close\r\nContent-Type: application/json\r\nContent-Length: {}\r\n",
        request.path,
        request.body.len()
    );
    for (name, value) in &request.headers {
        head.push_str(&format!("{name}: {value}\r\n"));
    }
    head.push_str("\r\n");
    let wire = format!("{head}{}", request.body);

    exchange_raw(endpoint, wire, timeout).await
}
```

Then refactor the connection half of `fetch_endpoint` into a shared `exchange_raw`, so GET and POST use identical resolution, budgeting, failure classification, and TLS handling:

```rust
/// Resolve, connect, send a prepared request, and read the response, all
/// under one timeout budget.
async fn exchange_raw(endpoint: &Endpoint, wire: String, timeout: Duration) -> Exchange {
    let started = Instant::now();

    let addrs = match tokio::time::timeout(
        timeout,
        tokio::net::lookup_host((endpoint.host.as_str(), endpoint.port)),
    )
    .await
    {
        Ok(Ok(addrs)) => addrs.collect::<Vec<_>>(),
        Ok(Err(_)) => return Exchange::Unresolvable,
        Err(_) => return Exchange::TimedOut,
    };
    if addrs.is_empty() {
        return Exchange::Unresolvable;
    }

    let remaining = timeout.saturating_sub(started.elapsed());
    if remaining.is_zero() {
        return Exchange::TimedOut;
    }
    let stream = match tokio::time::timeout(remaining, TcpStream::connect(addrs.as_slice())).await {
        Ok(Ok(stream)) => stream,
        Ok(Err(e)) if e.kind() == std::io::ErrorKind::ConnectionRefused => {
            return Exchange::Refused;
        }
        Ok(Err(e)) => return Exchange::Failed(e.to_string()),
        Err(_) => return Exchange::TimedOut,
    };

    let remaining = timeout.saturating_sub(started.elapsed());
    if remaining.is_zero() {
        return Exchange::TimedOut;
    }

    let result = match &endpoint.security {
        Security::Plaintext => {
            tokio::time::timeout(remaining, send_over(stream, wire)).await
        }
        Security::Tls { pinned_sha256 } => {
            tokio::time::timeout(
                remaining,
                crate::tls::send_tls(stream, &endpoint.host, wire, *pinned_sha256),
            )
            .await
        }
    };

    match result {
        Ok(Ok(body)) => Exchange::Response {
            body,
            latency_ms: elapsed_ms(started),
        },
        Ok(Err(e)) => Exchange::Failed(e.to_string()),
        Err(_) => Exchange::TimedOut,
    }
}

/// Write a prepared request and read the capped response, over any stream.
pub(crate) async fn send_over<S>(mut stream: S, wire: String) -> std::io::Result<String>
where
    S: tokio::io::AsyncRead + tokio::io::AsyncWrite + Unpin,
{
    stream.write_all(wire.as_bytes()).await?;
    let mut response = Vec::new();
    let mut limited = tokio::io::AsyncReadExt::take(stream, MAX_RESPONSE_BYTES);
    limited.read_to_end(&mut response).await?;
    Ok(String::from_utf8_lossy(&response).into_owned())
}
```

```rust
//! Decoding the enrollment payload a Cave QR code carries.
//!
//! The wire format is defined by Cave's `enrollment-payload.ts`. This is the
//! other half of a cross-repository contract, so the tests use vectors copied
//! from Cave's own tests: a divergence must fail in CI rather than at a
//! user's first scan.

use coven_transport::{Endpoint, Security};
use serde::{Deserialize, Serialize};

/// Scheme the app registers so a scanned code routes to it.
const ENROLLMENT_SCHEME: &str = "opencoven-chat://";

/// Supported payload version.
const ENROLLMENT_VERSION: u32 = 1;

/// One address to try, in priority order.
#[derive(Debug, Clone, PartialEq, Eq, Deserialize, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct EnrollmentCandidate {
    /// Hostname or IP literal.
    pub host: String,
    /// TCP port.
    pub port: u16,
    /// Whether to speak TLS.
    pub tls: bool,
    /// Lowercase hex SHA-256 of the DER certificate. Required when `tls`.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub pin_sha256: Option<String>,
}

/// Everything a phone needs from one scan.
#[derive(Debug, Clone, PartialEq, Eq, Deserialize, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct EnrollmentPayload {
    /// Payload version.
    pub v: u32,
    /// Cave instance identity, so a swapped instance is detectable.
    pub instance_id: String,
    /// Pairing request to exchange.
    pub pairing_request_id: String,
    /// Single-use pairing secret.
    pub pairing_secret: String,
    /// Expiry, epoch milliseconds.
    pub expires_at: i64,
    /// Addresses to try, in priority order.
    pub candidates: Vec<EnrollmentCandidate>,
}

impl EnrollmentPayload {
    /// Whether this payload's grant has expired at the supplied time.
    ///
    /// The clock is a parameter so expiry is testable and so the host decides
    /// what "now" means.
    pub fn is_expired(&self, now_epoch_millis: i64) -> bool {
        now_epoch_millis > self.expires_at
    }

    /// Convert candidates into transport endpoints, in priority order.
    ///
    /// Fails on a TLS candidate whose pin is missing or malformed. Decoding
    /// tolerates such a payload so the caller can report precisely what is
    /// wrong; connecting must not, because an unpinned TLS connection is the
    /// one thing this design refuses to make.
    pub fn endpoints(&self) -> Result<Vec<Endpoint>, EnrollmentError> {
        self.candidates
            .iter()
            .map(|candidate| {
                if !candidate.tls {
                    return Ok(Endpoint::plaintext(candidate.host.clone(), candidate.port));
                }
                let pin = candidate.pin_sha256.as_deref().ok_or_else(|| {
                    EnrollmentError::Malformed(format!(
                        "TLS candidate {} has no certificate pin",
                        candidate.host
                    ))
                })?;
                let bytes = decode_hex32(pin).ok_or_else(|| {
                    EnrollmentError::Malformed(format!(
                        "TLS candidate {} has a malformed certificate pin",
                        candidate.host
                    ))
                })?;
                Ok(Endpoint::tls(candidate.host.clone(), candidate.port, bytes))
            })
            .collect()
    }
}

/// Why an enrollment payload could not be used.
#[derive(Debug)]
pub enum EnrollmentError {
    /// The URI scheme was not ours.
    Scheme(String),
    /// The payload version is not supported.
    Version(u32),
    /// The payload was absent, undecodable, or internally inconsistent.
    Malformed(String),
}

impl std::fmt::Display for EnrollmentError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Scheme(found) => write!(f, "unexpected enrollment scheme {found}"),
            Self::Version(found) => write!(f, "unsupported enrollment payload version {found}"),
            Self::Malformed(detail) => write!(f, "malformed enrollment payload: {detail}"),
        }
    }
}

impl std::error::Error for EnrollmentError {}

/// Decode a scanned enrollment URI.
pub fn decode_enrollment_uri(uri: &str) -> Result<EnrollmentPayload, EnrollmentError> {
    let rest = uri
        .strip_prefix(ENROLLMENT_SCHEME)
        .ok_or_else(|| EnrollmentError::Scheme(uri.chars().take(32).collect()))?;

    let query = rest
        .split_once('?')
        .map(|(_, query)| query)
        .ok_or_else(|| EnrollmentError::Malformed("no query string".to_string()))?;

    let data = query
        .split('&')
        .find_map(|pair| pair.strip_prefix("d="))
        .ok_or_else(|| EnrollmentError::Malformed("no payload parameter".to_string()))?;

    let bytes = base64url_decode(data)
        .ok_or_else(|| EnrollmentError::Malformed("payload is not base64url".to_string()))?;
    let json = String::from_utf8(bytes)
        .map_err(|_| EnrollmentError::Malformed("payload is not UTF-8".to_string()))?;
    let payload: EnrollmentPayload = serde_json::from_str(&json)
        .map_err(|e| EnrollmentError::Malformed(format!("payload did not match v1: {e}")))?;

    if payload.v != ENROLLMENT_VERSION {
        return Err(EnrollmentError::Version(payload.v));
    }
    if payload.candidates.is_empty() {
        return Err(EnrollmentError::Malformed("no candidates".to_string()));
    }
    Ok(payload)
}

/// Decode 64 lowercase hex characters into 32 bytes.
fn decode_hex32(hex: &str) -> Option<[u8; 32]> {
    if hex.len() != 64 {
        return None;
    }
    let mut out = [0u8; 32];
    for (index, chunk) in hex.as_bytes().chunks(2).enumerate() {
        let text = std::str::from_utf8(chunk).ok()?;
        out[index] = u8::from_str_radix(text, 16).ok()?;
    }
    Some(out)
}

/// Base64url encode without padding, matching JavaScript's `base64url`.
///
/// Test-only: the phone decodes enrollment payloads and never produces them.
/// Cave is the encoder. Compiled out of shipping builds so it cannot become a
/// second, drifting implementation of the wire format.
#[cfg(test)]
fn base64url_encode(input: &[u8]) -> String {
    const ALPHABET: &[u8; 64] =
        b"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_";
    let mut out = String::new();
    for chunk in input.chunks(3) {
        let b0 = chunk[0] as u32;
        let b1 = *chunk.get(1).unwrap_or(&0) as u32;
        let b2 = *chunk.get(2).unwrap_or(&0) as u32;
        let triple = (b0 << 16) | (b1 << 8) | b2;
        out.push(ALPHABET[(triple >> 18) as usize & 63] as char);
        out.push(ALPHABET[(triple >> 12) as usize & 63] as char);
        if chunk.len() > 1 {
            out.push(ALPHABET[(triple >> 6) as usize & 63] as char);
        }
        if chunk.len() > 2 {
            out.push(ALPHABET[triple as usize & 63] as char);
        }
    }
    out
}

/// Base64url decode without padding.
fn base64url_decode(input: &str) -> Option<Vec<u8>> {
    fn value(byte: u8) -> Option<u32> {
        match byte {
            b'A'..=b'Z' => Some(u32::from(byte - b'A')),
            b'a'..=b'z' => Some(u32::from(byte - b'a') + 26),
            b'0'..=b'9' => Some(u32::from(byte - b'0') + 52),
            b'-' => Some(62),
            b'_' => Some(63),
            _ => None,
        }
    }

    let bytes = input.as_bytes();
    let mut out = Vec::with_capacity(bytes.len() * 3 / 4);
    for chunk in bytes.chunks(4) {
        if chunk.len() == 1 {
            return None;
        }
        let mut acc = 0u32;
        for (index, byte) in chunk.iter().enumerate() {
            acc |= value(*byte)? << (18 - 6 * index);
        }
        out.push((acc >> 16) as u8);
        if chunk.len() > 2 {
            out.push((acc >> 8) as u8);
        }
        if chunk.len() > 3 {
            out.push(acc as u8);
        }
    }
    Some(out)
}
```

```rust
//! The UniFFI surface Chat for iOS talks to.
//!
//! Intentionally thin. Protocol behavior lives in `cave-core` and
//! `coven-transport`, which carry no FFI derives so they stay usable from a
//! CLI or a Tauri host. This crate only adapts types across the boundary.

mod enrollment;

pub use enrollment::{EnrollmentCandidateFfi, EnrollmentPayloadFfi};

uniffi::setup_scaffolding!();

/// Errors surfaced to Swift.
///
/// Deliberately specific: Swift renders a different message and a different
/// next step for each of these, and collapsing them into one case would
/// produce the generic "could not connect" this design exists to avoid.
#[derive(Debug, thiserror::Error, uniffi::Error)]
pub enum ChatError {
    /// A scanned enrollment code could not be used.
    #[error("enrollment error: {message}")]
    Enrollment {
        /// What was wrong with it.
        message: String,
    },
    /// Cave answered with a typed error.
    #[error("{code}: {message}")]
    Api {
        /// Stable machine-readable code.
        code: String,
        /// User-safe message.
        message: String,
        /// Whether retrying could succeed.
        retryable: bool,
    },
    /// Nothing answered at any candidate address.
    #[error("unreachable: {detail}")]
    Unreachable {
        /// Which failure was most informative.
        detail: String,
    },
    /// Cave answered but did not match the v1 contract.
    #[error("malformed response: {detail}")]
    Malformed {
        /// What did not parse.
        detail: String,
    },
}

impl From<cave_core::CaveError> for ChatError {
    fn from(error: cave_core::CaveError) -> Self {
        match error {
            cave_core::CaveError::Api(envelope) => Self::Api {
                code: envelope.code,
                message: envelope.message,
                retryable: envelope.retryable,
            },
            cave_core::CaveError::Malformed(detail) => Self::Malformed { detail },
        }
    }
}

/// Shared tokio runtime for async FFI calls.
///
/// UniFFI's async support drives futures on the caller's executor, but the
/// transport needs a reactor for timers and sockets. One runtime for the
/// process, created on first use.
pub(crate) fn runtime() -> &'static tokio::runtime::Runtime {
    use std::sync::OnceLock;
    static RUNTIME: OnceLock<tokio::runtime::Runtime> = OnceLock::new();
    RUNTIME.get_or_init(|| {
        tokio::runtime::Builder::new_multi_thread()
            .enable_all()
            .build()
            .expect("the process cannot function without a tokio runtime")
    })
}

/// Version of this FFI surface, for diagnostics.
#[uniffi::export]
pub fn ffi_version() -> String {
    env!("CARGO_PKG_VERSION").to_string()
}
```

```rust
use crate::ChatError;

/// One candidate address, as Swift sees it.
#[derive(Debug, Clone, uniffi::Record)]
pub struct EnrollmentCandidateFfi {
    /// Hostname or IP literal.
    pub host: String,
    /// TCP port.
    pub port: u16,
    /// Whether to speak TLS.
    pub tls: bool,
    /// Lowercase hex SHA-256 certificate pin, when `tls`.
    pub pin_sha256: Option<String>,
}

/// A decoded enrollment payload, as Swift sees it.
#[derive(Debug, Clone, uniffi::Record)]
pub struct EnrollmentPayloadFfi {
    /// Cave instance identity.
    pub instance_id: String,
    /// Pairing request to exchange.
    pub pairing_request_id: String,
    /// Single-use pairing secret.
    pub pairing_secret: String,
    /// Expiry, epoch milliseconds.
    pub expires_at: i64,
    /// Candidate addresses in priority order.
    pub candidates: Vec<EnrollmentCandidateFfi>,
}

impl From<cave_core::EnrollmentPayload> for EnrollmentPayloadFfi {
    fn from(payload: cave_core::EnrollmentPayload) -> Self {
        Self {
            instance_id: payload.instance_id,
            pairing_request_id: payload.pairing_request_id,
            pairing_secret: payload.pairing_secret,
            expires_at: payload.expires_at,
            candidates: payload
                .candidates
                .into_iter()
                .map(|candidate| EnrollmentCandidateFfi {
                    host: candidate.host,
                    port: candidate.port,
                    tls: candidate.tls,
                    pin_sha256: candidate.pin_sha256,
                })
                .collect(),
        }
    }
}

/// Decode a scanned enrollment URI.
///
/// The error message describes the failure without echoing payload contents:
/// the payload carries a single-use grant, and a message containing it could
/// reach a log or a screenshot.
#[uniffi::export]
pub fn decode_enrollment(uri: String) -> Result<EnrollmentPayloadFfi, ChatError> {
    cave_core::decode_enrollment_uri(&uri)
        .map(Into::into)
        .map_err(|error| ChatError::Enrollment {
            message: match error {
                cave_core::EnrollmentError::Scheme(_) => {
                    "the scanned code is not an OpenCoven Chat enrollment code".to_string()
                }
                cave_core::EnrollmentError::Version(version) => {
                    format!("this app does not support enrollment payload version {version}")
                }
                cave_core::EnrollmentError::Malformed(_) => {
                    "the scanned code was damaged or incomplete".to_string()
                }
            },
        })
}
```

```bash
# Build the Rust core for iOS and generate Swift bindings + XCFramework.

#   build/ChatIOSCore.xcframework   (static lib + headers, device + sim)

PROFILE="${PROFILE:-release}"
CARGO_FLAG=""
[ "$PROFILE" = "release" ] && CARGO_FLAG="--release"

# Keep C dependencies (ring) aligned with the app's minimum OS.
export IPHONEOS_DEPLOYMENT_TARGET="${IPHONEOS_DEPLOYMENT_TARGET:-17.0}"

LIB_NAME=libchat_ios_ffi
TARGET_DIR=rust/target
OUT=build
BINDINGS="$OUT/bindings"

echo "==> Building Rust core (device + simulator, $PROFILE)"
(cd rust && cargo build -p chat-ios-ffi $CARGO_FLAG --target aarch64-apple-ios)
(cd rust && cargo build -p chat-ios-ffi $CARGO_FLAG --target aarch64-apple-ios-sim)

echo "==> Building host cdylib for bindgen metadata"
(cd rust && cargo build -p chat-ios-ffi $CARGO_FLAG)

echo "==> Generating Swift bindings"
rm -rf "$BINDINGS"
(cd rust && cargo run -p chat-ios-bindgen $CARGO_FLAG --bin uniffi-bindgen -- \
    generate --library "target/$PROFILE/$LIB_NAME.dylib" \
    --language swift --out-dir "../$BINDINGS")

mkdir -p app/Sources/Generated
cp "$BINDINGS"/*.swift app/Sources/Generated/

echo "==> Assembling XCFramework"
HEADERS_IOS="$OUT/headers-ios"
HEADERS_SIM="$OUT/headers-sim"
for headers in "$HEADERS_IOS" "$HEADERS_SIM"; do
  rm -rf "$headers"
  mkdir -p "$headers"
  cp "$BINDINGS"/*.h "$headers/"
  cat "$BINDINGS"/*.modulemap > "$headers/module.modulemap"
done

rm -rf "$OUT/ChatIOSCore.xcframework"
xcodebuild -create-xcframework \
  -library "$TARGET_DIR/aarch64-apple-ios/$PROFILE/$LIB_NAME.a" -headers "$HEADERS_IOS" \
  -library "$TARGET_DIR/aarch64-apple-ios-sim/$PROFILE/$LIB_NAME.a" -headers "$HEADERS_SIM" \
  -output "$OUT/ChatIOSCore.xcframework"

echo "==> Done: $OUT/ChatIOSCore.xcframework"
```

```swift
import Foundation
import Security

/// Errors from Keychain operations.
///
/// Operations throw rather than failing silently. A credential that appears
/// to save but did not is worse than a visible error, because the failure
/// surfaces later as an unexplained loss of pairing.
enum KeychainError: Error, Equatable {
    /// The Security framework returned an unexpected status.
    case unexpectedStatus(OSStatus)
    /// A stored value was not valid UTF-8.
    case malformedValue
}

/// Storage for the Cave bearer and other small secrets.
///
/// Items are stored `AfterFirstUnlockThisDeviceOnly` and explicitly
/// non-synchronizable, so a credential cannot ride an iCloud backup onto a
/// different device. Pairing is per-installation by design; a restored backup
/// must re-enroll.
enum Keychain {
    private static let service = "ai.opencoven.chat"

    /// The query identifying one item. Exposed for tests that assert
    /// attributes rather than values.
    static func baseQuery(for key: String) -> [String: Any] {
        [
            kSecClass as String: kSecClassGenericPassword,
            kSecAttrService as String: service,
            kSecAttrAccount as String: key,
            kSecAttrSynchronizable as String: false
        ]
    }

    /// Store a value, replacing any existing one.
    static func set(_ value: String, for key: String) throws {
        let data = Data(value.utf8)
        let query = baseQuery(for: key)

        let updateStatus = SecItemUpdate(
            query as CFDictionary,
            [kSecValueData as String: data] as CFDictionary
        )
        if updateStatus == errSecSuccess {
            return
        }
        guard updateStatus == errSecItemNotFound else {
            throw KeychainError.unexpectedStatus(updateStatus)
        }

        var addQuery = query
        addQuery[kSecValueData as String] = data
        addQuery[kSecAttrAccessible as String] = kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly

        let addStatus = SecItemAdd(addQuery as CFDictionary, nil)
        guard addStatus == errSecSuccess else {
            throw KeychainError.unexpectedStatus(addStatus)
        }
    }

    /// Read a value, or `nil` if absent.
    static func get(_ key: String) throws -> String? {
        var query = baseQuery(for: key)
        query[kSecReturnData as String] = true
        query[kSecMatchLimit as String] = kSecMatchLimitOne

        var result: AnyObject?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        if status == errSecItemNotFound {
            return nil
        }
        guard status == errSecSuccess else {
            throw KeychainError.unexpectedStatus(status)
        }
        guard let data = result as? Data,
              let value = String(data: data, encoding: .utf8)
        else {
            throw KeychainError.malformedValue
        }
        return value
    }

    /// Remove a value. Absent keys are not an error.
    static func delete(_ key: String) throws {
        let status = SecItemDelete(baseQuery(for: key) as CFDictionary)
        guard status == errSecSuccess || status == errSecItemNotFound else {
            throw KeychainError.unexpectedStatus(status)
        }
    }
}
```
