because a blocked lane never counts as a pass.

- **Published AppImage (#525).** As with v0.0.6, **Install Coven** installed Coven, then the engine
  install stopped with "The engine install did not finish: Error: download failed". The release
  AppImage passes its bundled libraries to the system `curl`. The AppImage built in the 24.04 CI
  image from the same source completed setup and every judged row. The release notes give the
  workaround.
- **Published MSI.** Blocked for the reason in the 2026-10-24 record: wry sets WebView2's
  `AdditionalBrowserArguments`, so no debugging port opens in a shipped build. The test build,
  which differs only by that port, completed every row. Owner: wry/Tauri upstream, or a product
  decision for Chat (Val).
- **Published `.deb`.** **Open** handed the system opener exactly
  `https://example.com/handoff-check?x=1`, `http://example.com/` and `https://[::1]:8080/x`, once
  each, and a second press delivered nothing more. Both **Copy table Markdown** buttons put the
  exact table source on the clipboard at 480×520 with Larger text.
