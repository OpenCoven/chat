This record distinguishes reviewed source and candidate tests from the published installers and their native acceptance. The release fixes the reported merge conflicts and three Settings defects: missing keyboard access to scrolling content, lost WebKit text-size clicks, and a collapsed project list in short windows. ## Limits retained

The native evidence comes from fresh CI users. Both macOS runner reports identify SIP as disabled and Accessibility/event/screen access as enabled for the automation helper; these are the observed CI conditions, not a hand-run on a user’s Mac.

Published native acceptance covers the two macOS DMGs, Windows MSI and Linux deb. The published Windows setup EXE and Linux AppImage have checksum and release-smoke evidence; the content CI’s AppImage candidate acceptance is a separate evidence class.

Native automation uses the real installed app, Coven CLI and engine with an API-key sign-in path and a deterministic local model fixture. It establishes those observed desktop flows and file effects; it does not establish live provider behavior, Claude subscription sign-in, physical iPhone behavior or human screen-reader acceptance. The original human/device gates in #515, #520 and #465 remain separate, as does the spoken-reason acceptance for the Orca issue #592. Windows signing (#411), updater acceptance (#539) and reading Cave grants on Windows (#587) retain their existing limits. Approval prompts remain off pending #573; this release retains full access.
