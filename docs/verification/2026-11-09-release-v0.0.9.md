### The v0.0.8 findings, on the published v0.0.9 installers

- **#544, Quote selection by Tab** (row 504-3). Tab from a dragged passage that ends on a link
  reached **Quote selection**: 18 presses past **Handoff check**, **Plain address** and **Loopback
  six** on macOS arm64, macOS x64 and Linux. Enter held on the action quoted once, a table cell
  quoted, and a selection across two messages offered no action.
- **#545, the separator's value** (row 504-6). VoiceOver read "vertical splitter 360 pixels Resize
  inspector 360 pixels wide…" and "376 pixels" after Left on both macOS lanes. Orca read
  "vertical splitter Resize inspector. 360 pixels wide…" on Linux. NVDA read the name and value on
  Windows.
- **#546, typed text in WebView2's `Web Data`** (row 504-8, Windows). After quitting, no browser
  storage file contained the draft text, and local storage held only
  `opencoven.chat.navigation.v1` and `opencoven.chat.preferences.v1`.
- **#547, the web view's page menu** (row 504-1, Windows and Linux). A right-click on a link with
  nothing selected opened no menu, while the same reader read the menu on a selection in the same
  reply, which offered only **Copy**.
- **#548, Settings' inspector width on Linux** (row 504-6, Linux). The width reached AT-SPI as
  `400px` and later `600px`, and **Reset** restored 360px. The **Inspector width** label and its
  hint are **not** proven: the row keeps the first 200 characters of the dialog's text, which stop
  before that row. Orca was not run on that Settings row. #548 stays open for those.

On both macOS lanes, the IME step committed "🇯🇵" rather than "日本" after the quote; that step is
recorded, not judged, and the quote stayed intact.
