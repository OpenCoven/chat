# OpenCoven Chat v0.0.7

This release rebuilds Chat from the current source. **The app itself is unchanged from
v0.0.6**: no feature, fix or setting is new, so updating is optional. What changed is how
Chat is checked: every change is now installed and driven through its window on Linux and
Windows in CI (see *Behind the scenes*).

Like the earlier versions, this is an early `0.x` pre-release without auto-update. Download
newer versions from the Releases page.

## Before you install

**Windows.** Two installers are published for 64-bit Windows 10 and 11 on x64 processors:
`OpenCoven.Chat_0.0.7_x64_en-US.msi` and `OpenCoven.Chat_0.0.7_x64-setup.exe`. Either one is
fine: the `.exe` installs for your user only, the `.msi` for everyone on the computer. There is
no build for Windows on ARM.

Neither installer is signed. The first time you run one, Windows SmartScreen shows **Windows
protected your PC** with an *Unknown publisher*. To continue:

1. Check the download first. In PowerShell:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\OpenCoven.Chat_0.0.7_x64-setup.exe
   ```

   The hash must match that file's line in `SHA256SUMS` from the same release.
2. In the SmartScreen dialog, choose **More info**, then **Run anyway**.

**macOS and Linux.** As before: the disk images are notarized, and the Linux `.AppImage` and
`.deb` are unsigned. If anything Chat needs is missing, it opens on **Set up Coven Chat**
instead of the chat.

To check any download, run this in the folder that holds it and `SHA256SUMS`:

```bash
shasum -a 256 -c --ignore-missing SHA256SUMS
```

## Known issue: the AppImage on newer Linux

On newer distributions such as Ubuntu 24.04, the AppImage's **Install Coven** step installs
Coven but then stops at the engine with *"The engine install did not finish: Error: download
failed"*. The AppImage passes its own bundled libraries to the programs Chat starts, and the
system's `curl` can't run with them
([#525](https://github.com/OpenCoven/chat/issues/525)). v0.0.6 has the same problem.

Until it's fixed, either install the `.deb` instead, or install the engine from a terminal and
then choose **Check again**:

```bash
~/.local/bin/coven engine install
```

## Behind the scenes

- Each change is now installed in CI, set up from an empty profile through the window, and
  driven through the link review, quoting, tables, the inspector, storage and the
  hand-off to your browser on Linux (`.deb` and AppImage) and Windows. The results are recorded
  in the repository. macOS, screen readers and keyboard input methods are still checked by
  hand.
