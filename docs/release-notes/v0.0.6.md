# OpenCoven Chat v0.0.6

This release adds **Settings › Model**, so you choose what runs your
messages, and makes replies easier to work with: links are reviewed before
they open, a selected passage can be quoted into your draft, and Markdown
tables can be copied or expanded. **Delete chat** now removes everything a
chat left on disk. The inspector gains a **Missions** tab, which needs a newer
Coven than any released so far.

Like the earlier versions, this is an early `0.x` pre-release without
auto-update. Download newer versions from the Releases page. The pipeline for
auto-update is in place; the app side follows in a later release, once its
signing key exists.

## Before you install

**Windows.** Two installers are published for 64-bit Windows 10 and 11 on x64
processors: `OpenCoven.Chat_0.0.6_x64_en-US.msi` and
`OpenCoven.Chat_0.0.6_x64-setup.exe`. Either one is fine: the `.exe` installs
for your user only, the `.msi` for everyone on the computer. There is no build
for Windows on ARM.

Neither installer is signed. The first time you run one, Windows SmartScreen
shows **Windows protected your PC** with an *Unknown publisher*. To continue:

1. Check the download first. In PowerShell:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\OpenCoven.Chat_0.0.6_x64-setup.exe
   ```

   The hash must match that file's line in `SHA256SUMS` from the same release.
2. In the SmartScreen dialog, choose **More info**, then **Run anyway**.

The release pipeline can now sign Windows installers through SSL.com eSigner.
The signing account is not set up yet, so this release still ships unsigned;
a signed one will remove the warning.

**macOS and Linux.** As before: the disk images are notarized, and the Linux
`.AppImage` and `.deb` are unsigned. If anything Chat needs is missing, it
opens on **Set up Coven Chat** instead of the chat.

To check any download, run this in the folder that holds it and `SHA256SUMS`:

```bash
shasum -a 256 -c --ignore-missing SHA256SUMS
```

## What's new

**Choose what runs your messages**
- **Settings › Model** has two groups. **New chats › Runs on** picks Coven
  Code (the default), Codex or Claude Code for chats that start from now on;
  an existing chat keeps what it started on, and the inspector's **Overview**
  shows it under **Runs on**. **Every message** sets a **Model** id (empty for
  the engine's default), **Think longer** and **Speed** for everything sent
  from this window.
- Codex isn't sent Think longer or Speed, because Coven ignores both for it;
  the settings say so. Attaching files is offered only where Coven Code runs
  the message. A model id that isn't one is marked in Settings and stops a
  send before anything leaves the window, with the draft kept.
- When a run reports which model answered, the inspector's **Activity** tab
  shows it under **Model**.
- Messages sent from the iPhone companion keep the engine's defaults.

**Links in replies are reviewed before they open**
- A link in a reply no longer opens on its own. Clicking it, or pressing Enter
  on it, shows **Open this link?** with the site on its own line and the full
  address as plain text, and the link's own words when they differ. Choose
  **Open**, **Copy address** or **Cancel**. Middle-click, modifier-click and
  the context menu never open a link behind your back.
- **Open** hands the exact reviewed address to your default browser and says
  "Sent the address to your browser". If no page opens, **Copy address** is
  there. An address with a sign-in name (`https://name@site/`) can only be
  copied.
- Links to IPv6 addresses such as `https://[::1]:8080/` are reviewed like
  any other instead of being refused.

**Quote a passage into your draft**
- Select text inside one message and **Quote selection** appears above the
  composer. It appends the passage to the end of your draft as Markdown
  quote lines, keeps whatever was already there, and sends nothing. A
  selection that spans two messages offers nothing.

**Tables**
- Each Markdown table in a reply has **Copy table Markdown**, which copies
  the table's exact source, and **Expand table**, which opens it in a sheet
  with room to read. Links inside the sheet go through the same review.

**Resize the inspector**
- In the wide layout, drag the inspector's left edge to resize it, or Tab to
  **Resize inspector** and use Left, Right, Home and End. The conversation
  always keeps its room; a narrower window holds the inspector under your
  width and gives it back when there is space. **Settings › General** shows
  the width and has **Reset**.

**Missions (needs a newer Coven)**
- The inspector has a **Missions** tab for asking a familiar to look into
  something in a project, read-only and on this computer, without a chat.
  No released Coven has missions yet: with Coven 0.4.10 the tab says
  "Missions need a newer version of Coven" and sends nothing. With a Coven
  that has them, the tab shows the exact familiar version Coven has on record
  before you send, follows the mission with Coven's own state names, and
  reports plainly when nothing ran. Nothing in it starts a paid cloud run.

## Fixed

- **Delete chat** now removes every transcript the chat is made of, not only
  the newest one, and the files you attached to it. Chats you didn't delete,
  and anything Chat didn't write, are left alone. Once per launch, while no
  run is active, Chat also removes what earlier versions' deletes left behind.
- The release pipeline retries Apple's notarization stapler when the
  connection drops, so a stapled image is not reported as unstapled, and the
  generated release body gives a `shasum` command that checks only the
  installers you downloaded.

## iPhone

The companion's newest TestFlight build, 0.2.0 (1507), works with this
version of Chat on the Mac. Deleting the companion from the phone now removes
its pairing, so a reinstalled app asks to pair again; the Mac's shared access
stays valid until **Forget paired phones**. When iOS has Local Network access
off for the app, the companion names the setting and offers **Open
Settings**. Device checks of that build are still in progress.
