# OpenCoven Chat v0.0.5

This is the first release with a Windows build. The Windows installers are
not code-signed yet, so Windows warns before the first run; the section below
says what to expect. macOS and Linux are unchanged from v0.0.4.

Like the earlier versions, this is an early `0.x` pre-release without
auto-update. Download newer versions from the Releases page.

## Before you install

**Windows (new).** Two installers are published for 64-bit Windows 10 and 11
on x64 processors: `OpenCoven.Chat_0.0.5_x64_en-US.msi` and
`OpenCoven.Chat_0.0.5_x64-setup.exe`. Either one is fine: the `.exe` installs
for your user only, the `.msi` for everyone on the computer. There is no build
for Windows on ARM.

Neither installer is signed. The first time you run one, Windows SmartScreen
shows **Windows protected your PC** with an *Unknown publisher*. To continue:

1. Check the download first. In PowerShell:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\OpenCoven.Chat_0.0.5_x64-setup.exe
   ```

   The hash must match that file's line in `SHA256SUMS` from the same release.
2. In the SmartScreen dialog, choose **More info**, then **Run anyway**.

Code signing for Windows is tracked separately and will remove the warning in
a later release. Chat uses the WebView2 runtime that Windows 11 and up-to-date
Windows 10 already include; the installers download it if it is missing.

**macOS and Linux.** As before: the disk images are notarized, and the Linux
`.AppImage` and `.deb` are unsigned. If anything Chat needs is missing, it
opens on **Set up Coven Chat** instead of the chat.

## What's new

**Windows build**
- Chat runs on Windows with the same first-run setup as on macOS and Linux:
  it checks for the Coven CLI, its engine, a signed-in model provider and a
  familiar, and installs or creates what is missing. On Windows, **Install
  Coven** puts Coven under `%LOCALAPPDATA%\Programs\OpenCoven\Coven`, for your
  user only. A Coven installed with `npm install -g @opencoven/cli` is found
  too.
- **Stop** ends the whole run. Every run is contained in a Windows Job Object
  that closes with it, so the Coven CLI and everything it started are gone
  when you stop a reply, and nothing is left behind in Task Manager.
- **Cmd+,** is **Ctrl+,** on Windows, and the other shortcuts follow the same
  rule. **Settings › About** shows the version and whether Coven is connected.

This is the first Windows build anyone outside the project can run. If a
reply never arrives, setup cannot find something you installed, or a window
looks wrong, please open an issue with the step and a screenshot.

## Fixed

- The release pipeline now reads the product name and version back from each
  Windows installer before publishing, and the Release body states whether
  the Windows installers were signed.
