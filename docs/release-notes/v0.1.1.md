# OpenCoven Chat v0.1.1

This patch aligns the released source with its conformance authority and fixes an early timeout in the iPhone acceptance fixture. It carries the full-access familiar chats introduced in v0.1.0.

Familiar chats now run with full access under your desktop user account. A normal message can change files and run commands beyond the familiar's workspace without an approval prompt. This applies to new chats and continuations using Coven Code, Codex, or Claude Code, including messages sent from a paired iPhone.

## Access and paired phones

**Settings → Access** explains the effective access. The projects listed there describe the familiar's declared project access; they do not limit a chat run. Operating system permissions still apply.

Pairing lets your phone read conversations and start full-access runs on your computer. Share pairing links only with your own phone. **Forget paired phones** revokes all current phone credentials. Old approval requests cannot authorize a run, and Chat does not show approval prompts for ordinary messages.

**Stop** still cancels the running reply and its processes. Conversation ownership, archive and deletion checks continue to apply.

## Before you install

This is an early `0.x` prerelease without automatic updates. Download newer versions from the Releases page. The desktop release supports macOS on Apple silicon and Intel, Windows on x64, and Linux on x64. The iPhone companion is distributed separately through TestFlight; builds 0.2.0 and 0.3.0 work with this desktop version.

The macOS app and disk images are signed and notarized. Windows and Linux installers are unsigned. Windows SmartScreen may show **Windows protected your PC** with an unknown publisher. Verify the download against `SHA256SUMS`, then choose **More info** and **Run anyway** if you want to install it.

Download `SHA256SUMS` alongside your installer. On macOS or Linux, hash the installer you downloaded; for example, for the Apple silicon disk image:

```sh
shasum -a 256 OpenCoven.Chat_0.1.1_aarch64.dmg
```

Compare the hash with the line for that exact filename in `SHA256SUMS`. For Intel macOS or Linux, replace the example filename with your downloaded installer's filename.

On Windows, use `Get-FileHash -Algorithm SHA256` in PowerShell and compare the result with that installer's line in `SHA256SUMS`.
