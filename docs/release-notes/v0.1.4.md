# Coven Chat v0.1.4

Coven Code chats now stop after a set number of model rounds, and you can continue them from where they stopped. The Windows installers are signed from this release on. This release follows v0.1.3, and it needs Coven 0.5.1 and engine 0.9.3, which setup installs for you.

## Coven Code chats have a model-round allowance

Each message to a Coven Code familiar now gets a fixed number of model rounds. A round is one turn of the model, and it may run tools. Set the number in **Settings › Model › Model rounds**. It's 50 unless you change it, and it can be any whole number from 1 to 4294967295. The allowance counts rounds only. It doesn't limit time, tokens or cost.

When a reply uses its whole allowance, the chat marks it **Unfinished** and keeps what it wrote so far. Choose **Continue saved work** to go on from the saved tool results. Work that already finished isn't repeated.

## Setup updates Coven and its engine

The allowance needs Coven 0.5.1 and engine 0.9.3. If you're updating from v0.1.3, Chat opens on setup the first time, because v0.1.3 installed Coven 0.4.10, which can't take an allowance. Choose **Update Coven**. Setup then updates the engine too, because v0.1.3 installed engine 0.9.1. If another copy of Coven on your computer comes first, setup names it, and you update that copy yourself.

## Signed Windows installers

The Windows installers, the `.msi` and the `-setup.exe`, are now signed with an Authenticode code-signing certificate and timestamped. Earlier versions' Windows installers were unsigned. Windows can now confirm who published the installer and that it hasn't changed since it was signed. The installer's **Properties › Digital Signatures** shows the signature.

SmartScreen may still show **Windows protected your PC** for a while, now naming the publisher instead of an unknown one. A new certificate earns SmartScreen's trust as more people download it, and that takes time. Verify the download against `SHA256SUMS`, then choose **More info** and **Run anyway** if you want to install it.

If you installed v0.1.3, **Check for updates** in **Settings › About** offers this version. You don't need to download it again.

## Before you install

This is an early `0.x` prerelease, and it updates itself: v0.1.3 and later offer each new release under **Settings › About**. The desktop release supports macOS on Apple silicon and Intel, Windows on x64, and Linux on x64. On Linux, Coven and its engine need glibc 2.39 or newer (Ubuntu 24.04 or later, for example), and the engine needs the ALSA library (`libasound2t64` on Ubuntu). On older systems such as Ubuntu 22.04 or Debian 12, Chat opens but its setup can't finish. It was tested with Coven 0.5.1 and engine 0.9.3. **TODO (coven-cave-c9): the iPhone companion builds that work with it, once native acceptance has run.**

The macOS app and disk images are signed and notarized. The Windows installers are signed and timestamped (see above). The Linux installers are unsigned.

Download `SHA256SUMS` alongside your installer. On macOS or Linux, hash the installer you downloaded; for example, for the Apple silicon disk image:

```sh
shasum -a 256 Coven.Chat_0.1.4_aarch64.dmg
```

Compare the hash with the line for that exact filename in `SHA256SUMS`. For Intel macOS or Linux, replace the example filename with your downloaded installer's filename.

On Windows, use `Get-FileHash -Algorithm SHA256` in PowerShell and compare the result with that installer's line in `SHA256SUMS`, for example for `Coven.Chat_0.1.4_x64-setup.exe`.
