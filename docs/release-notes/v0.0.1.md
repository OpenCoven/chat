# OpenCoven Chat v0.0.1

The first public build of OpenCoven Chat — a desktop client that brings your
local Coven CLI sessions and familiars into one conversation interface.

This is an early `0.x` release, published as a pre-release. It ships without
auto-update: to move to a newer version, download it from the Releases page.

## What it does

- **Talk to your local Coven CLI.** Pick a familiar in the sidebar and chat with
  it; every message is sent on that familiar's behalf. No account, no cloud
  round-trip — the app drives the CLI already on your machine.
- **Readable transcripts.** Markdown with GitHub-flavoured tables, task lists and
  code blocks, rendered inline. Links open externally; images resolve to labels
  rather than fetching remote content.
- **Tool activity in line.** Tool calls appear as their own rows in the
  transcript, so a run reads as a sequence of steps instead of a wall of text.
- **Attachments.** Send up to 4 text or code files, 64 KiB each. Unsent files
  stay in the composer until you remove or send them.
- **The CLI stays the source of truth.** Conversations, familiars and session
  state are read from your local Coven install on each load rather than mirrored
  into a second store in the app, so what you see matches what the CLI has.
- **Responsive layout.** The familiar sidebar and inspector collapse into
  overlay drawers on narrow windows, and return focus correctly when dismissed.

## Known limitations

- **No auto-update.** This release ships no updater manifest; newer versions are
  a manual download.
- **Access controls are not surfaced.** Permission rules and approvals live in
  Coven itself. This app does not define or enforce an additional boundary, and
  the Access tab says so rather than implying otherwise.
- **Screen sharing and tool-approval controls are unavailable.**
- Requires a working local Coven CLI installation. Opened without one, the app
  shows a connection notice rather than a transcript.

## Under the hood since the 0.0.1-demo.1 preview

Most of the nine hundred-odd commits behind this release are correctness and
infrastructure work rather than new surface area:

- The app consolidated onto a **single entrypoint**. The earlier demo-surface
  switching (`?demo=`, `VITE_DEFAULT_DEMO`, a separate demo bundle) is gone; the
  app opens directly on the real chat surface.
- Substantial **Windows hardening** around the session supervisor: ephemeral
  profile ownership, directory-quota accounting scoped to validated ancestors,
  and diagnosis of terminations blocked by retained file handles.
- A **real-authority conformance harness** and a contract canary now run in CI
  against the Coven and Cave clients.
- The frontend was reduced to a thin view over the native runtime. Client-side
  persistence was dropped in favour of reading through to the CLI, which removed
  a whole class of divergence between app state and CLI state.
