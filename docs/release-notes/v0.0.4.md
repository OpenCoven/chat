# OpenCoven Chat v0.0.4

Chat can now set itself up. On a computer with no Coven at all, it can install
Coven and its engine and sign you in to a model provider, then open the chat.
This release also adds a Settings dialog, groups tool calls into one line, and
brings the new Coven Chat icon.

Like the earlier versions, this is an early `0.x` pre-release without
auto-update. Download newer versions from the Releases page.

## Before you install

You no longer need to set up Coven first. If anything is missing, Chat opens on
**Set up Coven Chat** instead of the chat. Builds are for macOS and Linux;
there is still no Windows build.

## What's new

**First-run setup**
- Before the chat opens, Chat checks four things:
  - the Coven CLI is installed;
  - its engine is installed;
  - a model provider is signed in;
  - at least one familiar exists.
- If they're all in place, you won't see the setup screen at all.
- **Install Coven** downloads Coven 0.4.9 from its official GitHub release,
  checks the download against a fingerprint built into Chat, and installs it
  for your user only. It then goes straight on to install the engine. Each
  step shows its progress and can be stopped with **Cancel**. If one fails,
  it says why and offers **Try again**. You don't need Node.js or a terminal.
- **Sign in with Claude** uses your Claude subscription through Claude Code.
  If Claude Code isn't installed, setup shows the command that installs it.
  **Sign in with ChatGPT** appears once the engine is installed. Sign-in
  always happens in your browser, with the provider. Chat never sees your
  password.
- Every step also shows the terminal command, for those who'd rather run it
  themselves. **Check again** re-runs the checks.
- When Coven and its engine are installed but sign-in or a familiar is still
  missing, **Continue to Chat** opens the chat anyway.
- To create your first familiar, you still need Coven itself or Cave for now.
  Creating one from this screen arrives with the next Coven release.

**Settings**
- A gear in the sidebar and in the chat header opens **Settings**, and so does
  **Cmd/Ctrl+,**. It has these sections:
  - **General:** text size and whether to group tool calls.
  - **Chats:** whether to show archived chats.
  - **Access:** each project the familiar is declared to reach, with a copy
    button for its path.
  - **Devices:** the iPhone companion.
  - **Shortcuts.**
  - **About:** the version, whether the Coven CLI is connected, and what the
    app keeps on your computer.
- **Escape** closes an open dialog without also closing the side panels
  behind it.

**Tool calls and attachments**
- Two or more tool calls in a row fold into one line, such as "Ran 3 commands
  and read 1 file". Click it to see each call. You can turn this off in
  **Settings › General**.
- Attachments in the composer show the first lines of the file. Click one to
  see the whole file.

**The new Coven Chat icon**
- The crown-and-speech-bubble icon replaces the placeholder in the Dock and
  the app switcher, and appears in **Settings › About**.

**Finding Coven**
- Chat now finds a Coven installed with `npm install -g @opencoven/cli` when
  Node.js is managed by nvm, even when Chat is opened from Finder. It also now
  passes Claude Code's location to the engine, so a Claude subscription works
  from a Chat opened in Finder too.

## Fixed

- **Disk images are notarized.** The disk images themselves are now notarized
  and stapled, not only the app inside. macOS checks them without a warning,
  even offline.
- **Checksums match.** Download names in `SHA256SUMS` now match the files
  GitHub serves (dots instead of spaces), so `shasum -c SHA256SUMS` passes
  on the downloaded files.

## iPhone

The iPhone companion is still in internal testing through TestFlight. Its
build for this release, 0.2.0 (build 1454), works with this version of Chat
on the Mac. It brings:

- the new icon and a redesigned pairing screen;
- replies rendered as Markdown, as on the Mac, with code blocks you can copy;
- tool calls folded into one line that opens to show each call, and a live
  line saying what the familiar is doing;
- familiar cards that show what each familiar does, its current chat, and
  whether it is replying or archived;
- long-press to copy, select or share a reply, and **⋯ › Connection
  Details** for the Mac's address and certificate.
