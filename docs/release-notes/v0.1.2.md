# OpenCoven Chat v0.1.2

This release clears the text that earlier versions left in the web view's autofill data on Windows, gives the composer a new layout, adds controls to **Settings › Model** and **Settings › Access**, and fixes how Chat finds a familiar's saved conversation. Familiar chats run with full access, as in v0.1.0.

## Fixed: Windows kept old autofill entries

v0.0.9 stopped the web view on Windows from saving what you type ([#546](https://github.com/OpenCoven/chat/issues/546)), but what v0.0.8 and earlier had already saved stayed in `%LOCALAPPDATA%\ai.opencoven.chat\EBWebView\Default\Web Data`. Each time Chat starts on Windows, it now clears the web view's saved autofill entries, and nothing else. Your selected familiar, Settings and transcripts are kept. If clearing fails, Chat still starts and notes the error in its log ([#578](https://github.com/OpenCoven/chat/issues/578)).

macOS and Linux never stored typed text this way.

## The composer

- **A new layout.** The message field sits above a toolbar, with a details row under it: the familiar and its access (**Full access**), the engine and model the next message uses, and the chat's project. The row's **Model settings** button opens **Settings › Model**, including in an archived chat ([#543](https://github.com/OpenCoven/chat/issues/543)).
- **Esc stops a run.** While a familiar replies, press Escape in the message field or the conversation to stop the run. Your draft stays. Escape closes an open dialog, drawer or the find bar first, and a held key doesn't stop the run.

## Settings

- **Settings › Model › Every message** has a dropdown: **Engine default**, the engine's presets, or **Custom model** for a model ID you type. Coven Code's Claude presets are sent as plain model IDs, such as `claude-sonnet-5-5`, because Coven Code sends a prefixed `anthropic/…` ID to Anthropic unchanged.
- **Settings › Access** shows a familiar's declared project access in a list that scrolls and that the keyboard reaches, with a filter once the list is long. **Refresh project access** reads the grants again. To change grants, use the familiar's **Projects** tab in Coven Cave, then refresh in Chat. The projects describe declared access; they don't limit a chat run.

## Fixed

- **A familiar's saved conversation.** When Coven's session list leaves out a familiar's conversation, Chat now looks it up directly. If it still can't load, Chat says so on that familiar's chat, instead of showing the start of a new conversation, and suggests **Refresh Coven**. You can keep messaging the other familiars.
- **Coven Code's home folder.** Chat now starts Coven Code the way Coven does, so Coven Code reads its settings and goals from Coven's own home (`~/.coven/code`) rather than a separate `~/.coven-code`.
- **The inspector's width, read once.** VoiceOver read the **Resize inspector** handle's width twice. It now reads it once ([#579](https://github.com/OpenCoven/chat/issues/579)).
- **Security updates.** Chat's library for encrypted connections, rustls, is updated to 0.23.46. It secures the connection to a paired iPhone and Chat's own HTTPS requests ([#599](https://github.com/OpenCoven/chat/pull/599)).

## Known issues

- **Settings › Access on Windows.** Chat can't read Coven Cave's project grants on Windows yet. Settings says so and points to the familiar's **Projects** tab in Coven Cave, instead of saying that no access is declared ([#587](https://github.com/OpenCoven/chat/issues/587)).

## Before you install

This is an early `0.x` prerelease without automatic updates. Download newer versions from the Releases page. The desktop release supports macOS on Apple silicon and Intel, Windows on x64, and Linux on x64. The iPhone companion is distributed separately through TestFlight; builds 0.2.0 and 0.3.0 work with this desktop version.

The macOS app and disk images are signed and notarized. Windows and Linux installers are unsigned. Windows SmartScreen may show **Windows protected your PC** with an unknown publisher. Verify the download against `SHA256SUMS`, then choose **More info** and **Run anyway** if you want to install it.

Download `SHA256SUMS` alongside your installer. On macOS or Linux, hash the installer you downloaded; for example, for the Apple silicon disk image:

```sh
shasum -a 256 OpenCoven.Chat_0.1.2_aarch64.dmg
```

Compare the hash with the line for that exact filename in `SHA256SUMS`. For Intel macOS or Linux, replace the example filename with your downloaded installer's filename.

On Windows, use `Get-FileHash -Algorithm SHA256` in PowerShell and compare the result with that installer's line in `SHA256SUMS`.
